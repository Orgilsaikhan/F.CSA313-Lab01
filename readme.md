# Тестэд ашигласан

Playwright Test, Node.js ашигласан. Тестийн сайт нь saucedemo.com. Chromium, Firefox, WebKit гурван browser дээр ажиллуулсан, trace асаалттай, HTML тайлан гаргадаг болгосон.

logintest.spec.js дотор гурван тест гараар бичсэн: амжилттай нэвтрэх, буруу нууц үгээр амжилтгүй нэвтрэх, нэвтэрсний дараа бараа сагслах. Локатор нь голдуу getByRole ба getByText, зарим газар data-test атрибут, хоёр газар CSS class. Шалгалтад toBeVisible, toHaveURL, toContainText, toHaveCSS ашигласан.

codegen.spec.js-ийг playwright codegen-ээр бичүүлсэн. Нэвтрэх, бараа нээх, сагслах, checkout хийх, захиалга дуусгах, дараа нь бараа нэмээд сагснаас хасах урсгалыг бүхэлд нь бичсэн. Codegen өөрөө data-test атрибутыг сонгосон. Нэг assertion нэмсэн.

Assertion-оо албаар буруу болгож унагасан нь нэмэлт docs/trace_aldaatai.zip-д оруулсан байгаа. Энэд login хэсэгт оруулах нууц үгийг secret_sause болгож өөрчлөн унагасан.

# Playwright Selenium нарын ялгаа

Playwright ашиглах нь auto-wait, илүү хурдан ажиллагаа, орчин үеийн вэб аппуудыг илүү дээр тэстлэхэд амар болгодог. Selenium дээр бол WebDriverWait бичихгүй бол элемент ачаалж амжаагүйгээс тест унадаг, харин Playwright өөрөө хүлээдэг тул sleep огт бичээгүй. Assertion нь бас өөрөө дахин шалгадаг учраас flaky тест гараагүй. Суулгахад гурван browser хамт татагдсан, Selenium шиг driver-ийн хувилбар тааруулах шаардлага гарсангүй. Codegen нь Selenium IDE-тэй төстэй ч гаргаж өгсөн код нь цэвэрхэн байсан. Trace viewer дээр алхам бүрийг буцааж үзэж болдог нь том давуу талтай. Config дотор нэг мөр бичээд гурван browser дээр зэрэг ажиллуулж чадсан бол Selenium дээр Grid босгох ёстой болдог. Сул тал нь Playwright нь JavaScript төвтэй, Selenium шиг олон хэлний дэмжлэг, том сообщество багатай. Гэхдээ энэ лабораторийн хэмжээнд Playwright хурдан, бичихэд амар, тогтвортой байсан.

# XPath-аас яагаад зайлсхийсэн

XPath, ялангуяа codegen-ээс гардаг урт зам нь хуудасны бүтэц өчүүхэн өөрчлөгдөхөд шууд унана. SauceDemo дээр бараа нэмэх, хасахад жагсаалтын дараалал өөрчлөгддөг тул индекст тулгуурласан XPath найдваргүй байсан. Иймд эхлээд getByRole, getByText ашигласан, учир нь хэрэглэгч юу харж байгаагаар нь хайдаг тул уншихад ойлгомжтой. Дараа нь data-test атрибутыг сонгосон, энэ нь тусгайлан тестэд зориулж тавьсан учир дизайн өөрчлөгдсөн ч хэвээр үлдэнэ.
